# Episode 06 · Your First PyCharm Project

*Create, Write and Run Your First Program*

How to create your first project in PyCharm, write a two-line program with comments, run it with one click, and what the .idea and .venv folders in every project are for.

**Notes:** [06-your-first-pycharm-project.pdf](06-your-first-pycharm-project.pdf) (colour PDF, A4)

## Key points

- A **PyCharm project** is a folder on your disk; you pick its **location** and **name** in **New Project**, with the interpreter type left on **Project venv**.
- **New › Python File** adds the **.py** ending for you. A **#** starts a **comment**: Python skips it, and **Ctrl + /** toggles it.
- In Python, **a new line ends a statement**: no semicolons. Right-click › **Run 'hello'** shows the output in the **Run** window.
- Every project has **.idea** (PyCharm's settings) and **.venv** (its own private Python). Leave both alone.
