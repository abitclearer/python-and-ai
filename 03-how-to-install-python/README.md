# Episode 03 · How to Install Python

*Getting Started*

Installing Python means installing the interpreter, the program that runs your code. Get it from python.org; the latest version is Python 3.15.2 (November 2026).

**Notes:** [03-how-to-install-python.pdf](03-how-to-install-python.pdf) (colour PDF, A4)

## Key points

- "Install Python" really means: install the **Python interpreter**.
- Always download it from **python.org**. Latest version: **Python 3.15.2**.
- **Windows:** install the **Python install manager**, then type `python` in a terminal.
- **Mac:** run the macOS installer, then use **`python3`**. Check with `python --version`.
