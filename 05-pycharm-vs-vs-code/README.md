# Episode 05 · PyCharm vs VS Code

*Set Up Your Python Editor*

Why you write Python in an IDE instead of Notepad, how the two most popular editors compare, and how to download, install and first open PyCharm.

**Notes:** [05-pycharm-vs-vs-code.pdf](05-pycharm-vs-vs-code.pdf) (colour PDF, A4)

## Key points

- An **IDE** (Integrated Development Environment) puts writing, running and debugging your code in one app, and helps as you type.
- **VS Code** (48%) and **PyCharm** (25%) are the two most popular main editors for Python.
- This course uses **PyCharm**: everything for Python is built in, and the core features are **free forever**.
- Download it from **jetbrains.com/pycharm**, pick x64 or ARM64, click through Setup, then **Skip Import** on first launch.

Files in `code/mistakes/` are the mistakes shown in the video. They are meant to fail, so you can see the error for yourself.
