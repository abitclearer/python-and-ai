# Episode 01 · Why Learn Python Now?

*Course Introduction*

Since ChatGPT arrived in 2022, adding AI to everyday software has become one of the fastest-growing areas in tech. Python is the main language of AI, and this course takes you from zero to four real projects.

**Notes:** [01-why-learn-python-now.pdf](01-why-learn-python-now.pdf) (colour PDF, A4)

## Key points

- You don't need to train a model anymore. **You can just call one**, and prices keep falling.
- Apps use AI in three ways: **chat apps**, **cloud APIs**, and **local models** on your own computer.
- Python is **#1** on the TIOBE index (November 2026, 20.86%) and powers nearly half of all new AI repositories on GitHub.
- Six stages: two to learn the basics **by hand**, then four projects where AI coding tools join in.

Each program ends with a `# Output:` comment showing what it prints. To run one, install Python 3 from python.org,
then run `python <file>.py` in a terminal (on macOS and Linux: `python3 <file>.py`).

Files in `code/mistakes/` are the mistakes shown in the video. They are meant to fail, so you can see the error for yourself.
