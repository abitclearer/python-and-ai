# Episode 02 · What Is Python?

*Getting Started*

Python is a programming language created by Guido van Rossum and first released in February 1991. It's named after a comedy show, it's built to be easy to read, and it's the most popular language on the TIOBE index.

**Notes:** [02-what-is-python.pdf](02-what-is-python.pdf) (colour PDF, A4)

## Key points

- Python was created by **Guido van Rossum** and first released in **February 1991**.
- It's named after **Monty Python's Flying Circus**, not the snake.
- A programming language is a **precise** language that both humans and computers understand.
- Python took **#1 on the TIOBE index in October 2021** and still holds it (20.86%, November 2026).
